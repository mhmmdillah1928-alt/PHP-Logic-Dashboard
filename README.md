🌐 **Live Demo:** [https://php-logic-dashboard.vercel.app](https://php-logic-dashboard.vercel.app)

---

## 📌 Core Modules Overview

Dashboard ini terdiri dari **4 modul utama** yang masing-masing menguji dan mendemonstrasikan logika backend PHP:

1. 🧮 **Modul 01 - Basic Calculator:**
   * Eksekusi operasi aritmetika dasar (Penjumlahan, Pengurangan, Perkalian, Pembagian).
   * Dilengkapi validasi input numerik dan error-handling untuk pencegahan pembagian dengan nol (*division by zero*).

2. 🎓 **Modul 02 - Grade & Graduation Status Evaluator:**
   * Evaluasi nilai ujian berbasis logika pengkondisian PHP (`if-else`).
   * Mengonversi nilai angka menjadi predikat mutu huruf serta menentukan status kelulusan secara otomatis.

3. 🎲 **Modul 03 - Random Array Logic Analyzer:**
   * Generasi 10 nilai angka acak secara dinamis (rentang 1-100).
   * Memproses array untuk mengekstrak data statistik: angka ganjil terkecil, genap terbesar, serta kalkulasi selisih rentang nilai.

4. 📚 **Modul 04 - Course Grade Associative Array Processor:**
   * Pengolahan data nilai dari 5 mata kuliah menggunakan struktur data *Associative Array* PHP.
   * Melakukan iterasi array dan kalkulasi rata-rata nilai secara efisien.

## 🛠️ Tech Stack & Dependencies

* **Backend Logic:** PHP 8.2 (Serverless execution via `vercel-php`)
* **Styling & UI:** Tailwind CSS v3, FontAwesome Icons, Google Fonts (*Plus Jakarta Sans*)
* **Client Interactivity:** Vanilla JavaScript (ES6)
* **Deployment & CI/CD:** Vercel & GitHub Actions Workflow
